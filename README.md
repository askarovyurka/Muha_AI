# ИИ-решатель пятнашек на основе модели мозга мухи

>  **Статус проекта:** На этапе активной разработки (WIP). Скоро здесь появится нейробиологическая магия!

Проект по созданию искусственного интеллекта для решения головоломки типа «Патнашки» (15 Puzzle). За основу архитектуры алгоритма взяты принципы работы нервной системы и мозга мухи (биомиметический подход).

## 👥 Команда разработчиков

* Разработчик 1 - **Юра**
* Разработчик 2 - **Иван**
* Разработчик 3 - **Максим**

##  О проекте

Цель проекта — исследовать и применить принципы обработки информации, подсмотренные в живой природе (в биологических нейросетях насекомых), чтобы научить ИИ эффективно находить последовательность ходов для сборки пятнашек из любого перемешанного состояния.

##  Установка и запуск (в разработке)

*Внимание: На текущем этапе репозиторий содержит только структуру проекта документацию и htlm страничку. Исполняемый код ИИ находится в разработке.*

Как только релиз будет готов, запуск будет осуществляться примерно так:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/пользователь/репозиторий.git
cd название-репозитория

# 2. Установите зависимости (пример)
# pip install -r requirements.txt

# 3. Запустите ИИ-решатель (заглушка)
# python main.py

```

##  Git Workflow (Рабочий процесс)

В нашем проекте мы используем следующий командный workflow:

1. **Клонирование репозитория:**
```bash
git clone https://github.com/пользователь/репозиторий.git
cd название-репозитория

```


2. **Создание ветки для задачи:**
Для каждой новой функции или исправления создавайте отдельную ветку от `main`:
```bash
git checkout -b feature/имя-вашей-фичи

```


3. **Фиксация изменений (Коммиты):**
Делайте понятные коммиты:
```bash
git add .
git commit -m "Добавлено описание изменений"

```


4. **Отправка на GitHub:**
```bash
git push origin feature/имя-вашей-фичи

```


5. **Создание Pull Request:**
Зайдите на GitHub и откройте Pull Request из вашей ветки в `main` для код-ревью.
