Пятнашки для мухи

«Числа»: поле по размеру (например 4x4). «Текст»: введите ФИО, буквы разложатся по исходным индексам, цель: выстроить их по алфавиту. В каждом ряду есть пустая клетка.

Ходов: 0

WASD: выбор ячейки (курсор). Стрелочки: сдвинуть выбранную плашку. Enter / Пробел: быстрый сдвиг в соседнюю пустую клетку.

Поле из чисел

Введите размер: «4x4», «3x5» или просто «4». Формат: строки x столбцы.

Поле из текста

Введите строку. Она разобьётся на буквы (всегда в ВЕРХНЕМ РЕГИСТРЕ), встанет в матрицу по исходным индексам. Цель: расставить в алфавитном порядке.
